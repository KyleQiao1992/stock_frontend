**当前状态以[本轮复核报告](./chan-review-2026-10-16.md)为准。下文保留各轮开发与验证记录；其中历史测试计数、初始化限制和未改引擎的说明只对应当轮。**

界面移除数值表格、条件列表、合并步骤和规则说明。

发生包含合并的组会显示高、低价水平虚线，从左侧实际保留该价格的原K影线连接到右侧结果K线对应边界。高、低分别定位来源；没有合并的组不添加连接线。虚线随横向滚动与尺寸变化更新，来源滚出视窗时不连接到其他原K。

## 数据与时间的一致性

详情直接保留增量引擎 `point.elements` 的三根计算快照，并从完整输入的 `from/to` 范围还原来源；没有截取可见区间后另算一套分型。已完成笔端和分型圆点分别保存各自快照，避免同时间点的不同计算阶段互相覆盖。没有分型圆点的第一笔起点也有三角详情。

`isValid` 仅核对本次快照的四项几何条件；数据没有提供收盘确认元信息，不能把详情显示理解成已经单独验证收盘确认。数据刷新、更换股票 / 周期或关闭缠论后，旧数据的详情不继续展示。

详情功能最初没有改动笔规则；本轮审查已修复旧引擎的独立K、初始方向、同价候选和动态定位问题，见[当前复核报告](./chan-review-2026-10-16.md)。这些修复不代表整个缠论理论已完整实现或证明。

## 分型类型结论

弹窗底部显示实际分型所属类别：三根处理后K线均各自只来自一根原始K时，显示“第一种：直接顶分型/直接底分型”；任一根来自多根原始K时，显示“第二种：包含关系的顶分型/包含关系的底分型”。依据真实来源分组判断，不依据蜡烛颜色或是否有影线。浏览器检查已覆盖四种结论及手机布局。

## 顶分型的三种力度特征

依据作者[第82课](https://blog.sina.com.cn/s/blog_486e105c01000cq4.html)第56、60、64段，新增三个紧凑标注，出现在原有分型类别结论之后。点击标注可展开判断依据与软件阈值，手机和键盘也可使用。

| 标注 | 当前三根原K的识别条件 |
| --- | --- |
| 中继倾向 | 第一根阳线且实体占自身振幅至少60%；第二、三根的实体均大于0，且各不超过第一根实体的50%。表示倾向延续此前上涨方向，尚不是经后续行情确认的中继。 |
| 力度较大顶分型 | 第二根满足长上影或长阴，且不满足“第三根为阳线、收盘高于第二根高低区间中点”这一复合条件。 |
| 相对高点特征 | 第三根最低价严格小于第一根最低价，第三根收盘价不高于第一根高低区间中点。 |

“长阴”采用实体占该K振幅至少60%；“长上影”采用上影占该K振幅至少50%且不短于实体。60%/50%是软件实现约定，原文没有指定这些数值，也没有给出按三K就“几乎确定相对高点”的概率保证。第三项只比较实际价格，不使用上述长短阈值。

第二项严格保留原文的“以阳线”限定：第三根即使收在第二根区间中点以上，若是阴线或十字，也不属于“阳线收复半区”。不能把整个条件简化为 `close <= midpoint`。中点取高低区间的平均价，而非实体中点；触及第一根低点不等于跌破。

这三种描述可能重叠；结论优先展示相对高点特征、力度较大、中继倾向，并在展开说明中保留其他匹配项。优先级是产品展示规则，不代表统计概率。

自动识别范围限定为三根未合并的真实原K；包含后的区间缺少真实开收盘价，保持已有包含关系结论，不伪造实体套用规则。原文第二项举例包含“长阴吞没阳线”的特例，目前未自动覆盖该特例。底分型已按下节对称规则扩展。

识别只读取分型的三K快照，不读取后续行情，不改变笔、中枢或分型几何判定。数据没有收盘状态元信息，实时第三根更新时标签可能随数据变化。

本轮实际验证：170项缠论单元测试通过；浏览器验证三个独立三K示例的标签、底分型不分类、包含不套用OHLC条件、点击说明展开/收起及手机访问均通过；原有三栏、颜色/高低区间、虚线、滚动及数据切换检查仍通过。构建、修改文件ESLint、脚本语法和diff空白检查通过。没有部署。

## 底分型的三种力度特征

依据作者[第82课](https://blog.sina.com.cn/s/blog_486e105c01000cq4.html)关于底分型情况相反的说明，将顶侧规则按价格反射对称推导：

| 标注 | 当前三根无包含原K的识别条件 |
| --- | --- |
| 中继倾向 | 第一根满足软件实体占比的阴线，第二、三根为非零小实体，倾向延续此前下跌方向。 |
| 力度较大底分型 | 第二根长下影或长阳，且不满足“第三根为阴线、收盘低于第二根高低区间中点”。 |
| 相对低点特征 | 第三根最高价严格高于第一根最高价，且收盘不低于第一根高低区间中点。 |

长实体60%、小实体50%、长下影50%及下影不短于实体，沿用顶侧的软件实现约定。突破不含触及，中点条件包含等于；阳线或十字星即使收在第二根中点以下，也不能被误判为“阴线收于半区以下”。优先级为相对低点、力度较大、中继倾向，并在说明中保留其他重叠匹配。

实现以 `O'=-O, C'=-C, H'=-L, L'=-H` 反射三根原K，复用顶侧判定，再将结论和数值证据映射回底侧；不改变来源K线、OHLC、日期、分型或笔的计算结果。界面继续保留三图、原有结论和可点击说明；顶、底各自读取对应分类，没有将相对高点或向下成笔文案套到底分型。

同样仅使用三根计算快照，不读取未来行情，含合并时不套用实体规则，形态标注不表示后续走势已经确认。

本次实际验证：179项缠论单元测试通过；浏览器检查底三类独立示例、普通/包含分类、顶底属性隔离、桌面与手机说明展开/收起，并继续覆盖全部顶分型标签与原有展示回归，全部通过。生产构建、相关文件ESLint、脚本语法和diff空白检查通过。没有执行部署或线上验证。

## 本轮复核后的展示

标题标明“分型快照”或“笔端快照”及右K截至日期，防止把同一时间不同计算阶段误当成同一组三K。力度标注旁显示“软件形态参考”；非法OHLC明确显示“原K数据异常，未进行力度识别”。包含区间保持真实高度，H=L画同价水平线；虚线两端均须在内层、外层及弹窗的有效视窗中。最新结果和未实现范围见当前复核报告。
