# 完整页面浏览器验收

页面回归通过真实浏览器操作完整 `src/main.jsx → App → 登录 → 页面`。原有单元测试和 `scripts/check*` 图表诊断继续保留，但不作为页面验收的替代。

## 运行

首次在没有 Chrome 的机器上安装测试浏览器：`npx playwright install chromium`。Mac 默认使用已安装的 Chrome，其他位置可设置 `E2E_BROWSER`。使用现有 `playwright/test`，不需要新增测试依赖。

```sh
npm run test:e2e                 # 全部隔离页面、功能、布局测试
npm run test:e2e:functional      # 只跑完整 App 主流程
npm run test:e2e:visual          # 只跑全页面布局矩阵
npm run test:e2e:report          # 打开结果和失败附件
npm run test:acceptance         # 静态检查、构建、单元测试、浏览器测试
```

隔离服务默认监听 `127.0.0.1:5198`，可通过 `E2E_PORT` 修改；测试自行启动和关闭，不复用已有进程、不加载生产 Vite 配置、数据库或 `.env`。所有行情/业务数据均为测试数据，外部请求被禁止，未登记接口返回 404 并导致测试失败。测试服务仅用于本机，不能部署到线上。

## 两层结果必须分开

| 层次 | 验证内容 | 无法证明的内容 |
|---|---|---|
| 隔离完整 App | React 渲染、真实登录页面与导航、登记页面、输入/切换/加载竞态、错误恢复、布局 | 实际数据库、Redis、供应商、线上服务是否正常 |
| 真实本地服务 | 已启动的本地完整服务，不拦截接口，实际 A/HK/US 行情、资料、财报、历史和周期切换 | 未部署版本的线上状态、未执行的业务写入 |

真实验收需要专用测试账号的已登录浏览器状态文件。由用户在本机登录并保存到 git 忽略的 `.auth/`；不要把密码或状态文件贴到聊天。可在终端运行以下命令，在新打开的浏览器中手动登录，随后关闭窗口：

```sh
mkdir -p .auth
npx playwright codegen --save-storage=.auth/local.json http://localhost:5173
E2E_LIVE_STORAGE_STATE=.auth/local.json npm run test:e2e:live
```

真实验收缺少会话或服务不可达会失败，不会自动跳过变绿。真实模式关闭 trace/video，不导出会话，不发送收藏/账户修改或真实 Agent 聊天请求。测试报告和截图仍可能包含页面上的非公开内容，只保存在本机。

真实模式持续检查 HTTP 失败、传输错误、控制台警告/错误、未处理脚本异常和可见错误提示，并记录路径、方法、状态及耗时；恢复成功也会保留先前错误。诊断不收集查询参数、header、正文、存储或任意控制台消息。取消请求只在指定路径的用户切换完成、新结果断言成功并有成功请求证据时归类为正常取消，原取消记录仍保留。监控本身有独立隔离自测；这些自测通过不等于真实接口已验证。

## 页面与主功能覆盖

`tests/e2e/pages.mjs` 是页面清单。包括登录/注册、A/HK/US、趋势大盘五子页、Agent、成熟/预备/管理因子、账号管理/设置，以及证券分析各分类。港美股的缠论研判、笔端参考和成熟/预备因子的自选起始日均单独登记。每页检查实际图表蜡烛、数据行或对应内容；不能用“未崩溃”作为通过依据。

布局遍历 320、390、768、1280、1440、1920 像素宽度和深浅两种主题，检查页面横向溢出、可见文字重叠、非预期裁字及 SVG 中 OHLC/MA/指数图例的重叠和越界，并保存截图。主题必须同时通过实际主题属性和背景颜色检查。主动滚动的宽表允许内部横向滚动，明确的省略文本允许截断。全页截图不展开桌面端内部滚动区；证券分析分类另检查正文开头、末尾实际进入可见窗口后的布局，并保存对应滚动截图。几何检查不覆盖所有绘图标记间的遮挡，也不进行像素基准图比较，需结合报告截图复核。

功能用例重点覆盖首次进市场、默认收藏慢响应、初始化时编辑草稿、逐字输入、搜索选股、自选选股、K 线周期和全屏、独立资料请求、超过三秒的历史请求、财报实际三十秒截止及恢复、刷新、资讯、Agent 输入发送、权限以及分页失败重试。故障测试只对明确的接口状态码放行；其他报错仍然失败。逐字输入覆盖浏览器键盘事件；操作系统中文输入法的原生候选词交互尚不在自动化覆盖内。

日期流程还检查热力图单日/区间/六个预设、真实 1200ms 历史进度轮询、区间校验、休市空结果、失败重试与切日期取消；四指数的年份、MA60/MA20窗口和迟到响应；因子自选日期及硬刷新后的实际收益值。收藏夹在短窗口与多个宽度下检查内部文字和滚动。几何探测器单独证明同父元素文字重叠、弹层裁字会失败，明确省略号和实际可操作的内部滚动可通过。

## 2026-10-24 图表持续抖动回归

根因是桌面中列自动滚动条与自适应 SVG 高度构成反馈：财报错误等短内容接近最大高度时，滚动条出现会让 SVG 从 864×622 缩到 847×610；内容变矮后滚动条消失，又让 SVG 变宽、变高，随后再次溢出。指针移出后仍会循环，不能归因于鼠标悬停或日 K 行情轮询。

修复在中列滚动容器预留稳定滚动条空间，让宽度不再取决于当前是否溢出。保留原有独立滚动、响应式尺寸计算和财报错误显示，没有隐藏错误或停止正常更新。

`chart-stability.spec.mjs` 从完整 App 登录进入，模拟实际占用 17px 的系统滚动条；先量自然高度，再将窗口调整到溢出临界区。排除一次正常 resize 后逐帧采样 120 帧，并验证图表节点身份、尺寸、滚动条占位以及正文实际滚动。Playwright headless 默认隐藏滚动条，因此该 spec 明确移除 `--hide-scrollbars`，并检查实际占位；不能把宽度为 0 的环境记为该回归通过。

修复前两个用例确实失败：短财报场景 109 次尺寸变化，长财报切回短财报后 112 次，图表节点未替换。修复后同两例通过，短财报、长财报、资讯、切回短财报四个场景均 120 帧 0 次变化。证据分别保留在 `test-results/chart-stability-first-failure/` 和 `test-results/chart-stability-after-fix/`；最初滚动条环境未生效的前置失败另行保存，没有当作产品复现。
