本次明确标注为**换手率适配版**，没有完成与通达信或 moomoo 的逐值对照，不应称为原软件复刻。[米筐公开文档](https://www.ricequant.com/doc/rqdata/cli/manual)列出的常见 FSL 使用 `MAX(1,100*SUM(VOL,5)/(3*CAPITAL))`，而[通达信 DMA 文档](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)要求平滑权重在有效分数范围内。这里明确采用以下项目口径，不把未经验证的权重处理解释成供应商行为：

```text
SWL = (7 * EMA(CLOSE,5) + 3 * EMA(CLOSE,10)) / 10
A = MIN(1, MAX(0.01, SUM(VOL,5) / (3 * CAPITAL)))
SWS = A * EMA(CLOSE,12) + (1-A) * 上一周期SWS
```

EMA 用首根收盘价初始化；SWS 在第 5 根有效 K 线用 EMA12 初始化。CAPITAL 与 VOL 保持同一单位，优先用对应 K 线成交量及换手率反推。当历史换手缺失时，只允许属于最新 K 线同日/同周/同月的报价成交量及换手率估算当前流通股本，并显示“SWS估算”；这是当前股本校准的历史估算，不能用于声称无未来数据的回测。没有可用换手数据时保留可计算的 SWL、断开 SWS 并注明原因。页面 title 提供完整口径。
