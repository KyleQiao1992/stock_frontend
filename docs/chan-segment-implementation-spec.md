## 3. 输入、输出与不变量

### 输入

- 已声明版本、按时间递增的有效笔端链；顶底交替，方向与价格一致，价格有限。
- 同一批数据统一精度、周期、复权方式和历史起点。不得为了外观临时裁剪计算窗口。
- 缺失、无效或未确认笔端不能被跳过后继续拼接。已有 `confirmed` 的含义是当前上游结构的状态，并不保证今后不会回退。
- 历史起点影响结果；对未加载的更早行情不作“全市场唯一分段”承诺。

### 输出及证据

沿用 `segments` / `pending` 接口。完成段保留真实起止笔端、方向、笔数、内部最高低及来源、确认依据位置；候选段不冒充完成段。

正式实现应为每次确认保留可检查的证明对象：来源笔端、合并前后特征元素、所用包含方向、分型三元素、标准缺口、确认分支、第二序列证据（若需要）。端点时间与完成证据时间分开。

不变量：完成段至少三笔且为奇数，端点异性质、价格方向正确，相邻完成段共用端点且方向交替。后三笔重叠或一次反向笔突破，本身不是完成证明。固定且不撤回的笔链逐项追加时，确认结果不得利用未来笔；上游撤回时，则必须撤回失去依据的段。

## 4. 分支规格

| 编号 | 条件与行为 | 依据性质 |
| --- | --- | --- |
| S01 | 上行段取向下笔区间，下行段取向上笔区间，均保留端点来源 | 第67课 |
| S02 | 在允许包含的同性质序列内顺序合并；合并后的元素参与下一次比较 | 第65/67/71课 |
| S03 | 假设分界点前最后元素与分界后首元素不能无差别合并；分界后同性质元素仍合并 | 第71课；不能扩大为“所有包含都禁止” |
| S04 | 普通分支先取得实际用于分型的标准三元素，再计算第一、第二元素之间的缺口 | 第67课结合第71课的工程推导 |
| S05 | 标准顶/底分型成立且无缺口，才能走普通无缺口终结分支 | 第67课 |
| S06 | 有缺口时，等待从候选转折点开始的反向标准特征序列出现相应分型 | 第67课 |
| S07 | 第二序列正常处理包含；不额外要求补第一缺口，不再次递归分两类 | 第67/77/78课 |
| S08 | 首笔破坏的特殊分支必须证明候选分界的资格及反向发展，不能只看某条低点/高点越界 | 第71课与本轮反例推导；见下一节 |
| S09 | 第二序列未成立时若原方向恢复，不能保留伪造的A/B/C三段 | 第78/81课；等值恢复边界另列 |
| S10 | 第二序列形成确认的同一步，不能因价格随后越过旧端点而先行否定已成立的分型 | 第81课结构等价案例 |
| S11 | 内部极值与实际端点分开；不能强制所有段的端点都是内部绝对极值 | 第78课 |
| S12 | 新旧笔只改变输入划分；线段规则不按品种、周期或样本名称设特例 | 工程契约 |

## 5. 为什么不能只改缺口

反例笔端：`[0,100,40,120,50,115,110,114,105]`。

普通分支的标准特征序列是 `[40,100]、[110,120]、[105,114]`。第一、第二元素有缺口，反向序列未出现完成所需的分型，应该等待。当前代码却在合并前缓存无缺口，提前输出0→120。

第一版临时试验只把普通分支改为比较 `left` 和合并后的 `middle`。原反例通过，已有28项测试也全部通过，但扩展输入暴露另一问题：

```text
[0,100,40,120,50,115,110,114,105,113,40,112,45,114]
```

试验版在第11个笔端时将0→114提前确认。该候选点之前的标准元素为 `[110,120]`，候选首反向笔为 `[105,114]`：后者的高点已低于前者，并不具有这里用来替代普通顶分型的外包条件，代码却仅凭低点越界进入 `first_stroke_break`。

这不是要求所有段终点必须为全段最高点，而是在限定这一特殊确认捷径的适用范围；第78课内部极值不同于端点的用例仍须保留。

### 第二版临时方案

1. 普通分支以标准 `left/middle` 判断缺口，不再读取合并前缓存。
2. 首笔破坏捷径先确认外包资格：上行候选除低点条件外，首反向元素高点不得低于左元素高点；下行对称。否则回普通分型核验，不能直接确认。

第2项是从原文分型结构及第71课包含例外推导的分支前提，不是作者逐字提供的代码。临时试验表明它消除了本轮错选端点；仍需正式回归及边界验收，不能把两处布尔修改称为整套理论证明。

### 延长反例的正确完成路径

在上述14个笔端中，反向标准序列最终为 `[50,113]、[40,112]、[45,114]`，底分型到第14个笔端才出现。此时确认0→120及120→40，两者都不能把完成时刻写回更早的候选端点。

从真实计算入口构造相应闭合OHLC，每腿8根K、价格平移200且高低加减0.1，补充后继笔证据后：K82、K121不输出完成段，K122才输出 `segment-9-33` 与 `segment-33-89`。这是合成行情验证，不是真实市场服务或页面验收。
