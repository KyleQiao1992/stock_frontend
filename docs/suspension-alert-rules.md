# 停牌预警 · 规则与计算口径（2026-10-20 除权及窗口复核）

> 目标：对自选股做「停牌风险」预警。核心风险通道是 **异常波动 → 严重异常波动 → 强制停牌核查**。
> 本文锁定计算口径与阈值；机器可读配置见 [`server/suspensionRules.json`](../server/suspensionRules.json)。
> ⚠️ 标记的单元格是**尚未对到交易所现行原文**的，开工前必须确认（见文末「待确认清单」）。

---

## 1. 风险分级（自选股徽章 → 这套映射）

| 等级 | 含义 | 触发条件（任一） |
|---|---|---|
| 🟢 正常 | 无异动迹象 | 各项偏离值离阈值都还远 |
| 🟡 接近普通异波 | 快触发异常波动公告 | 近3日累计偏离值达到板块阈值的 ~80% |
| 🟠 已触发普通异波 / 接近严重异波 | 需披露异动公告；再走高就核查 | 已触发普通异波，或 10日/30日累计偏离值达严重档的 ~80% |
| 🔴 高停牌核查风险 | 已达严重异常波动标准 | 命中任一严重异常波动情形 → 交易所**可要求停牌核查** |
| ⛔ 已公告停牌 | 公司已公告将停牌 | 命中东财停复牌 feed |

> 文案统一用「**高停牌核查风险**」而非「必停牌」：触发严重异常波动后，规则是公司应核查披露、交易所**可**要求停牌核查，并非 100% 机械停牌。

## 3. 偏离值计算口径（沪深一致）

**区间累计偏离值**仍是个股与指数的复合区间涨跌幅之差，不是每日百分比简单相加：

```
个股区间增长因子 = ∏(当日原始收盘价 / 当日交易参考前收价)
偏离值 = (个股区间增长因子 - 指数期末收盘 / 指数期初前收盘) × 100%
```

没有除权除息时，个股增长因子相消后就是 `期末收盘 / 期初前收盘`。发生除权除息时，不能直接比较两个未经调整的原始端点。上交所《交易规则（2026年修订）》5.4.2（一）明确要求期间发生除权除息时调整收盘价格；4.3.2、4.3.3 规定除权日前收盘价和涨跌幅基准使用除权参考价；6.1 规定科创板未另行规定的事项适用本规则，6.12 的基准为科创50。

实现要点：
- 东财请求 `fqt=0`，以 `原始收盘价 - f60涨跌额` 恢复当日交易参考前收价；`f59涨跌幅`仅做一致性校验，避免连乘两位百分比的舍入误差。
- 腾讯只读取原始 `day`，用同源 `cqr/FHcontent` 中的派息、送股、转增事件恢复除权参考前收价，并取至0.01元；如果最新同日报价存在，再与 `qt[4]` 校验。使用原始 `kline/kline` 接口，不能把 `qfqday` 静默当成原始价格，未知分配方案/参考价冲突明确报错。
- 窗口按实际有成交的交易日计，不是自然日，零成交记录不占个股窗口；指数仍比较个股窗口起止日期，包含期间指数的全部变动。
- 缺少参考前收价、同期指数端点或31根有效个股日K时返回错误，不能输出“正常”。
- 结果缓存改用 `suspend-alert:reference-v3` 命名空间，并包含传入名称，不复用旧版除权误报；名称可能影响ST判断。
- 普通异常比较1..3日全部后缀，严重异常比较1..10及1..30日全部后缀。严重上涨/下跌阈值不对称，按各自阈值的相对比例选最接近触发的候选；不能仅按偏离绝对值选方向。完整 `dev3/dev10/dev30` 仍保留，严重候选单列 `metrics.seriousWindows`，原因使用实际天数。
- 最近一轮普通异波的公告后重置仍未实现，见第8节近似说明。

**688610 回归样本（截至2026-10-20）**：10月19日“10派2元转4股”，10月16日原始收盘113.00，除权参考前收为 `round((113-0.2)/1.4, 2)=80.57`，与10月19日真实报价的前收字段一致。旧代码直接将10月15日118.50与10月20日80.40比较，得到近3日偏离 **-30.89%**；改按交易参考前收链接后为 **-3.58%**，10日 **-11.66%**、30日 **-14.10%**，同向异波估算为0次。这些是行情样本复算结果，不是交易所发布的异动认定。

验证范围：腾讯重新实取的原始日K（688610、600519、科创50及上证A股指数均截至2026-10-20）、独立Decimal端点/断点调整复算、除权日前收快照及隔离接口回归；本轮东财真实网络请求失败，`f60`解析按字段语义和合成响应验证，未宣称实取核验了东财该股除权日数据。腾讯特殊除权公式没有完整覆盖，仅支持已声明的现金/送转方案。本轮原 `fqkline/get` 路径被WAF拦截，改用不复权专用 `ifzq.gtimg.cn/appstock/app/kline/kline`；已通过真实Node fetch验证HTTP200及正确60根日K。

## 4. 异常波动（普通）认定标准

连续 **3 个交易日内**收盘价涨跌幅偏离值累计达到下表阈值，即达到相应数值条件。这包含1日、2日及3日窗口，不能只检查固定3日。引擎比较三个结束于同一日的后缀窗口，取绝对偏离最大的窗口判定接近/达到阈值，并返回 `abnWindowDays` 和 `abnDeviation`；`dev3`仍保留完整3日指标。历史同向次数使用相同的3日内窗口规则，但仍是下文明确标注的上升沿估算，不含公告后的正式重置。

| 板块 | 普通股阈值 | ST 股阈值 | 量/价其他情形 |
|---|---|---|---|
| 沪市主板 | ±20% | ±12%（2026-07-06前）→ ±20%（2026-07-06起） | 换手率：日均换手率/前5日 ≥30倍 且 累计换手率 ≥20% |
| 深市主板 | ±20% | ±12%（2026-07-06前）→ ±20%（2026-07-06起） | 同上 + 振幅类 |
| 创业板 | ±30% | — | 单日偏离 / 换手率 / 振幅 |
| 科创板 | ±30% | — | 同上 |

> ST 阈值：主板 ST/\*ST 涨跌幅限制由 5%→10% 自 **2026-07-06** 实施，异动偏离值阈值同步由 ±12% 调到 ±20%。2026-07-06前为 ±12%，此后为 ±20%，引擎按日期切换（见 `suspensionRules.json` 的 `stThresholdChange`）。

## 5. 严重异常波动认定标准 → 强制核查/停牌核查

命中任一情形即属严重异常波动；公司应次日核查披露，交易所**可要求停牌核查**。

| 板块 | 10日累计偏离 | 30日累计偏离 | 次数类情形 |
|---|---|---|---|
| 沪/深主板 | **+100% / −50%** | **+200% / −70%** | 10个交易日内 **4次同向异常波动**（每次 = 一轮3日内±20%；媒体所称"10日4次同向涨停"即此条简化） |
| 创业板/科创板 | **+100% / −50%** | **+200% / −70%** | 10个交易日内 **3次同向异常波动**（每次 = 一轮3日内±30%） |

“10/30个交易日内”同样包括较短区间：例如新华传媒2026-10-09公告确认8个交易日偏离117.06%达到10日内严重阈值，开普云2025-09-23公告确认21个交易日偏离超过200%达到30日内严重阈值。因此不能只检查固定10/30日。

注意：**涨跌阈值不对称**——涨向 +100%/+200%，跌向 −50%/−70%。
指标**自交易所公布的次一交易日或复牌之日起重新计算**（对应"轮"的重置，需持久化每只票上一次触发日）。

## 6. 其他停牌风险（叠加，非偏离值类）

- **盘中临时停牌**：仅无涨跌幅限制票/新股，较开盘价首次 ±30% 停10分钟、±60% 停到14:57。需实时分时数据，本期可不做或后置。
- **计划性停牌**（重组/重大事项）：不可预测，靠东财停复牌 feed（`stock_tfp_em` → `datacenter-web.eastmoney.com/api/data/v1/get`，`RPT_CUSTOM_SUSPEND_DATA_INTERFACE`）公告后提前提醒。feed 是**前瞻**的，能拿到「N日后起停牌」。

## 8. 实现细则补充（engine 近似口径，非交易所原文）

> 这些是 `server/suspensionAlert.js` 在「纯现算、不落库」前提下对规则做的工程近似，记录在此以免被误读成交易所口径。

- **「同向异常波动次数」用3日内的1/2/3日窗口达到阈值的方向上升沿近似计数**（无 DB，不持久化「上一轮触发日」，故无法严格按交易所「公布次日/复牌起重算」重置）。同一轮持续触发只记 1 次；按涨/跌方向分别累计取较大值。
- **计数窗口左边界用前一天状态播种**：`prevTriggered` 初值取窗口左边界前一交易日3日内窗口的触发方向，避免把跨边界延续的同一轮触发误计成窗口内新发生的一次（曾导致临界票被高估到 4 次严重档）。
- **橙色档（`abnormal_or_near_serious`）标题动态命名**：`abnormalHit` 为真显示「已触发异常波动」，仅 `nearSerious`（慢牛：10/30 日偏离接近严重但任意 3 日 <20%）显示「接近严重异常波动」，不再一律标「已触发」。颜色/分级不变。
