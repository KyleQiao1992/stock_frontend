# 缠论主图

当前主图入口为 `src/lib/chan/index.js` 的 `analyzeChan`。笔使用增量包含/分型引擎及第62、65、77课旧笔独立K条件；2026-10-18已接入特征序列线段，详见[线段实现与验证范围](./chan-segments-2026-10-18.md)。

计算流程：固定周期请求窗口 → 增量K线包含/分型 → 笔破坏回退重算 → 滑动笔中枢 → 动态方向极值末端。日线请求300根后自动裁去起笔前历史；放大、缩小只改变可见范围。

黄色实线连接笔端及实际原K上的动态极值，三角标记笔端参考、圆点标记分型。紫色粗实线为已确认线段，紫色虚线为发展中线段参考，独立“线段”开关默认开启。线段记录起终端点、组成笔数和本次窗口复算的确认依据K；依据K不等于端点当时已知或系统跨窗口首次观测时刻。最新K未明确收盘时不用于确认。色框仍为滑动笔重叠区，蓝框为当前参考区，没有改称递归中枢。

普通主图和全屏主图使用同一组 `chanData` 和 `ChanOverlay`。`historyOffset` 约束缠论模式的可见历史起点，所有结构坐标仍对应原始加载历史；屏外端点通过SVG裁剪保留原始线形。

研判面板记录完成笔方向和现价相对参考笔中枢的位置；未递归计算走势级别、背驰和一二三类买卖点，因此不将这些结构位置当作已确认买卖点。

完整口径、原始基准、逐点测试和验收范围见 [参考站对照](./chan-reference-parity.md)。运行：

```sh
npm test
npm run test:chan-reference
npm run test:chan-render
npm run build
```

旧 `strictAnalysis.js` 整体流程仍仅供历史测试。主图复用其中的独立 `segment.js` 模块，并从当前笔引擎的同一完整请求窗口笔序列计算线段；动态尾笔不参与确认，发展中段必须先满足前三笔重叠。上游笔发生回退时线段同步重算，不冻结已失效的结构。当前修改尚未部署线上。
