# 缠论图层

主图工具栏的「缠论」默认关闭，划线与子选项均隐藏。每次开启时切换到近80根，之后可以自由选择其他K线数量；切换子选项或关闭缠论不改变显示根数。开启后可分别切换笔、中枢、分型。普通视图与全屏共享设置；本次会话内保留设置。

- 黄色实线：算法生成的笔；黄色虚线：连接最后笔端与末根收盘价的动态延伸段，不参与中枢计算。
- 红／绿圆点：顶／底分型。
- 半透明区域：历史中枢；蓝框：最新参考中枢。
- 结构定位不等于一二三类买卖点确认；新K线到来时，近端结构可能变化。

算法来自 tangle 的 `fractal.js`、`bi.js`、`zs.js`，保留 minGap=3、回撤吸收阈值0.25、中枢3至9笔的口径。
使用当前标的、周期、复权方式的最近300根有效K线计算；「近N根」仅控制显示，不参与计算。日线不足300根时使用已有历史。
跨窗口笔保留原始端点，由SVG裁剪，避免端点被挪到窗口边缘。数据直接复用主图，不增加行情请求。

模块：`src/lib/chan/`（计算）、`ChanOverlay.jsx`（SVG）、`ChanControls.jsx`（控制）。
验证：`npm test` 包含缠论测试，`npm run build` 构建。

## 图下研判与笔端参考

K线下方新增个股分析面板。默认缠论关闭时显示「资讯 / 资金动向」；开启缠论时自动选择「缠论研判」，并展示「笔端参考 / 资讯 / 资金动向」。关闭时返回资讯。右侧仍为自选/推荐，财报信息保留为下方独立卡片。

研判逻辑移植自 tangle 的 `outlook.js`，使用与SVG完全相同的300根窗口、已完成笔和中枢；仅在传入文字层前把序号映射回实际K线日期，保留中枢ID。未完成段不加入笔端列表。日/周/月随当前图表周期联动，显示根数不改变计算窗口。

展示结构事实、末笔高低点、中枢上下沿、观察/失效条件和三种条件情景。结构匹配分为原算法规则分数，不是概率；没有参考中枢时不显示中枢推演，不把假设标为已确认买卖点。中枢时间显示区间起止，不冒充上/下沿价格出现的K线日期。

浏览器验证：开启选80根；改120根再关闭仍保留120根；关闭后分析标签保留资讯和资金动向；已验证研判、笔端列表和资金动向标签。单元测试核对文字关键价、日期和中枢ID与图表结构一致。
