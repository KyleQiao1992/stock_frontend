# 缠论结构：原典严格老笔与特征序列线段

> 当前用户目标已改为复现参考网站的实际划线口径。本文件记录上一轮严格算法；它目前未通过网站对照，不能视为已完成网站对齐。最新基准、差异及门禁见 [参考网站划线对照](./chan-reference-parity.md)。

## 采用的定义

采用《教你炒股票》第62、65、77课的严格老笔口径，线段遵循第67、71、77、78课及第81课更正。不混入新笔、宽松笔、百分比回撤筛选。图上的K线周期是观察周期，不能直接当成走势类型的级别。

1. **包含处理**：按时间顺序处理相邻K线的包含，方向由此前两个无包含的处理后K线确定。向上取高点最大值、低点最大值，向下取高点最小值、低点最小值。分别保留高低点对应的真实原K线索引；同价极值采用较早的原K线定位。
2. **历史起点**：加载历史开头的包含链缺少此前方向，舍弃无法定向的前缀，从首对非包含K线开始。这是有限历史下的工程约定，不用后续行情回推开头方向。全为包含链时，不凭空生成结构。
3. **分型**：三根连续处理后K线，中间高、低均严格高于两侧为顶，均严格低于两侧为底。圆点标记分型候选，不意味着每个分型都能成为笔端。
4. **笔**：顶底交替，两端三K分型不能共用K线，之间至少一根不属于任何端分型的独立处理后K线。因此分型中心索引差至少4。检查顶底区间及笔内高低点条件，同类分型按极值替换，等价极值保留较早者。不按回撤比例删除已满足条件的笔。
5. **确认**：末端分型在形成反向有效笔前仍可被同类极值替换；最后一条候选笔画虚线，完成笔单独传入线段计算。虚线端点取方向上的真实高/低点，不连接末根收盘价。新行情可能修正近端结构，确认指当前数据下的状态。
6. **线段**：至少三笔、奇数笔，前三笔必须重叠。向上段特征序列取向下笔，向下段取向上笔。标准特征序列出现对应分型，首、次元素无缺口时确认第一种结束；有缺口时，必须等反向特征序列出现分型。假设分界点两侧不合并包含，反向第二序列按包含处理；不把单笔破坏直接当成段结束。
7. **线段中枢**：用三条连续完成线段的实际高低区间计算 ZD=max(low1,low2,low3)、ZG=min(high1,high2,high3)，要求 ZD<ZG。依第78课，线段实际区间可能超过端点价格，构枢使用全段高低点。核心上下沿由初始三段固定，后续延伸不收缩边界，也不在第九段截断。按时间顺序处理延伸、离开与回试，不枚举相互重叠的三笔滑窗。

色框明确标记为**线段中枢（本图最小级别）**。更高走势级别需由连续次级别走势类型递归构造；本实现未生成高层递归走势类型及其扩张中枢，不将线段框标为“日线级别中枢”，不将框间关系断言为已确认趋势。

## 绘图与交互

- 黄色实线：当前数据确认的笔；黄色虚线：未确认候选笔。
- 紫色实线：按特征序列确认的线段；紫色虚线：未完成线段。
- 红、绿圆点：处理后K线的顶、底分型候选。
- 半透明框：线段中枢；蓝框：当前未结束的中枢。
- 分型、笔、线段、线段中枢可分别开关；普通视图与全屏共用计算及设置。

使用当前标的、周期、复权方式的**全部已加载有效K线**计算，取消此前300根截断。“近N根”只改变显示。跨窗口结构保留原始端点，由SVG裁剪，不把端点挪到窗口边缘。复用主图行情，不新增请求。

## 结构研判

研判与笔端列表使用与SVG相同的结构，并将内部序号映射为真实日期。ZG/ZD日期取初始构枢线段实际提供该高低点的K线，不能用中枢起止时间冒充。

只呈现完成笔方向、确认线段、线段中枢和现价相对位置。取消按末笔方向和框位置生成的一二三类观察、人工结构分数及仓位建议。

- 一类点需要对应级别趋势背驰及次级别证据。
- 二类点依赖一类点和其后的首次次级别回调/反抽。
- 三类点需要次级别走势离开中枢后，首次次级别回试/回抽完成，且满足不越过ZG/ZD的条件。

这些走势类型和背驰证据尚未计算，界面明确显示未确认买卖点，位置关系和笔端参考不能替代确认。
