# 缠论主图

当前主图入口为 `src/lib/chan/index.js` 的 `analyzeChan`，默认采用用户指定参考站的划线口径。主图不再使用原典严格老笔、特征序列线段或线段中枢。

计算流程：固定周期请求窗口 → 增量K线包含/分型 → 笔破坏回退重算 → 滑动笔中枢 → 动态方向极值末端。日线请求300根后自动裁去起笔前历史；放大、缩小只改变可见范围。

黄色实线连接笔端并延伸至最后K线时间上的动态极值。三角标记笔端参考、圆点标记分型；动态末端没有笔端三角，不参与中枢计算。色框为笔中枢，蓝框为当前参考中枢；不绘制紫色线段或虚线尾段。

普通主图和全屏主图使用同一组 `chanData` 和 `ChanOverlay`。`historyOffset` 约束缠论模式的可见历史起点，所有结构坐标仍对应原始加载历史；屏外端点通过SVG裁剪保留原始线形。

研判面板记录完成笔方向和现价相对参考笔中枢的位置；未递归计算走势级别、背驰和一二三类买卖点，因此不将这些结构位置当作已确认买卖点。

完整口径、原始基准、逐点测试和验收范围见 [参考站对照](./chan-reference-parity.md)。运行：

```sh
npm test
npm run test:chan-reference
npm run test:chan-render
npm run build
```

旧严格实现仅保留为独立算法及历史测试，不参与当前主图。当前修改尚未部署线上。
