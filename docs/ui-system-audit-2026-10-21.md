### 新发现并修复

本轮产品修改均在 `AShareTD9InteractiveChart.jsx` 内：

1. **因子详情翻页显示旧行。** 原实现翻页后保留旧结果；加载失败时表格仍是前一页，页码却已改变。现在结果绑定提交的查询、页码和重试版本；加载中不显示旧表格和统计，失败提供重试及上一页，失效响应不能更新页面。
2. **旧简称搜索污染新输入。** 原实现等名称查询返回后直接改写股票代码，随后才判断请求是否已过期。现在 A 股和港股名称查询返回后先检查请求归属及输入内容；输入变化时立即清空旧联想项，避免新代码被回车误选成旧建议。
3. **自选、推荐请求互相串扰。** 原加载与错误状态在市场之间共享，推荐没有绑定查询版本。现在状态按市场保存，编辑列表或修改推荐因子/日期会使旧请求失效；旧响应不能覆盖新结果或错误。还修复了切回市场后默认列表覆盖用户编辑的问题：默认列表只初始化一次，手动编辑和失败信息保留。
4. **中文输入法确认键提前发送 Agent 消息。** Agent 原键盘处理没有检查组合输入。现在组合输入和键码 229 直接保留输入法行为；普通 Enter 仍发送，Shift+Enter 仍换行。
5. **把加载/失败误报为没有推荐。** 原空列表分支不检查加载与错误状态，读取中或失败时也显示“今天没有符合要求”。现在加载显示真实进度状态，失败保留错误，只有没有错误且已结束加载的空列表才显示空结果。
