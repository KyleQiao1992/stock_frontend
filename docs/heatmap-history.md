# 历史热力图（接口 + 内存缓存）

在趋势大盘 / 热力图选择「指定日期」或「日期区间」，填写日期后点击查询。默认仍为最新行情。查询区间最长366天。

当前历史数据源为同花顺行业目录及年度日线，采用同花顺行业分类。与最新行情的东方财富分类不同，不拼接两家的行业或成分。面积为区间累计成交额（元转亿元），颜色为末日收盘相对首个交易日前收盘的涨跌幅，不是每日涨跌幅相加。休市日不补数据，悬浮显示实际起止日期及交易日数。一月查询按需获取上一年度末的收盘作为基准。

同花顺成分股分页入口在本机返回 HTTP 401，当前历史模式明确禁用下钻；最新行情仍保留原有成分股下钻。历史模式也不提供流通市值、主力净流入和历史全市场个股总览。禁止使用最新快照冒充历史数据。

历史入口沿用 `/api/market-heatmap?start=YYYY-MM-DD&end=YYYY-MM-DD`，保留登录鉴权。历史处理不读写 Redis 或 MySQL。`heatmapHistory.js` 负责查询任务，`heatmapThs.js` 提供行业目录和日线。原东方财富适配逻辑保留在服务工厂中，生产历史服务默认使用同花顺。

服务端内存缓存：行业目录1小时；年度日线当前年1分钟、过去年份6小时，最多600个年度条目。查询任务最多20个，同一时刻共享一个运行任务，避免重复点击堆叠请求。历史日线并发最多6个；先探测3个行业，全部失败即提前结束。后续工作预算90秒，在途请求8秒超时。失败行业及原因单独返回，前端标明部分数据。进度轮询约1.2秒，查询切换后旧响应不覆盖新查询。

数据入口：

- 年度日线示例：https://d.10jqka.com.cn/v4/line/bk_881121/01/2026.js
- 格式参考：https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_board_industry_ths.py
