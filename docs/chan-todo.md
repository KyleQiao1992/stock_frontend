## CHAN-BI-001：支持作者补充的新笔规则

- [ ] 实现并验证新笔规则。

记录日期：2026-10-24。状态：待实现。

### 背景与目标

当前主图采用旧笔条件：顶、底分型经过包含处理后，二者之间至少保留一根不属于两端分型的独立处理K线。

新增作者2007-09-18补充的新笔规则，使符合新规则、但不符合旧笔独立K条件的转折可以成笔。这是规则版本的扩展，不将采用旧笔本身判为算法错误。本条关注已收盘历史K线上的划分，盘中未收盘候选状态不列入本次需求。

### 规则要求

1. 仍先按方向、顺序处理K线包含关系，再识别顶、底分型。
2. 两端分型不得共用处理后的K线；这项条件不能放宽。
3. 在满足第2项的前提下，顶分型最高K与底分型最低K之间，排除这两根端点K，按不考虑包含关系的原始K线计数，至少有3根。
4. 新笔不再强制两个分型之间另有一根独立的处理K线；其余端点与选点规则仍需逐项核对，不能将上述两项距离条件当作完整算法。
5. 保留原始K与合并K的对应关系，确保计数可追溯；不能只把旧实现的最少处理K数量从7改成5。

### 验收要点

- [ ] 差异案例：原始区间按 `[高,低]` 为 `[[3,2],[2,1],[3,2],[3,2],[4,3],[5,4],[4,3]]`。K3与K4合并后，两端分型不共用处理K，但中间没有独立处理K；底K2与顶K6之间有3根原始K。旧笔不成立，新笔应成立。
- [ ] 边界案例：两端极值K之间仅有2根原始K时，不满足新笔距离条件。
- [ ] 共用案例：即使原始K数量充足，两端分型共用处理K时仍不能成笔。
- [ ] 覆盖上涨、下跌镜像，以及连续包含、等极值定位和原始K计数；原文未明确的边界须记录实现约定。
- [ ] 在实际主图计算入口验证，检查笔变化对后续线段和重叠区的影响；界面发生变化时补充完整App回归。
- [ ] 明确输出所用规则版本，并记录实现、测试结果与仍未验证的范围。
