# A股行情连接故障核查（2026-10-20）

## 实测根因

主图日/周/月K使用腾讯前复权 `fqkline/get`。原固定域名 `web.ifzq.gtimg.cn` 本轮对完全相同的参数返回HTTP501，响应正文指向腾讯WAF错误页，无CORS允许头。对应请求在 `ifzq.gtimg.cn` 返回HTTP200、`Access-Control-Allow-Origin: *`、`code: 0` 和真实 `qfqday` 数据。

分别模拟腾讯站内Referer和localhost Referer/Origin，结果相同。没有证据确认WAF拦截从何时开始、为何触发，不能归因为用户访问次数、IP封禁或本轮停牌计算修改。Git HEAD与此前工作区的K线请求域名相同。

自选名称通过同一个日K加载器取 `qt` 名称，故主图与名称一起失败。顶部指数使用独立的快照/原始行情接口，不受此复权路径故障影响。东财备用请求本轮被上游关闭连接，不能把浏览器所有 `Failed to fetch` 都解释成CORS。

## 修正

- 腾讯个股复权K线改用已实测成功的 `ifzq.gtimg.cn`，保留同源qfq/hfq参数和原价格口径。
- 不复权请求使用 `kline/kline`，不向缺少复权参数的 `fqkline/get` 请求。
- 总失败错误保留腾讯主来源原因，避免被后面的东财错误覆盖。
