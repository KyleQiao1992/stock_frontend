# 最新行情备用快照

东财 push2 不可用时，最新热力图和今日盘面共用一份经过验证的快照。A 股、港股、美股的个股行情接口和历史热力图不使用这个实现。

股票范围以新浪 `hs_a` 的完整已上市名单为基础，补充东财确认上市日期的 CDR。东财行业目录还包含待上市股票，不能直接充当交易名单。每个代码必须有唯一的东财二级行业归属；覆盖不足时拒绝生成行业图，不把缺失归属塞进“未分类”。

报价优先来自腾讯。价格、昨收、成交额和时间取自同一份逐股报价，`S` 状态明确标记停牌；停牌、旧日期和缺失报价不计入涨跌家数。成交额保留元精度，汇总展示为亿元。主力净流入和涨跌停池没有可用数据时保持未知。

行业归属来自 `RPT_F10_CORETHEME_BOARDTYPE` 的二级行业。市值来自 `RPT_VALUEANALYSIS_DET` 的 `TOTAL_MARKET_CAP` 和 `NOTLIMITED_MARKETCAP_A`，单位为元。后者与腾讯的流通市值对少数股票存在实质差异，不能互换。每份市值记录必须属于快照交易日，覆盖全部股票；有当日有效报价的股票还必须核对价格，才能计算原有的行业流通市值加权颜色。个别股票报价缺失或属于旧交易日时，保留经过验证的同日市值，将旧价格、涨跌幅和成交额清空。

该估值报告提供收盘数据。盘中持续更新尚未实测；缺少同日记录或价格不一致时拒绝新快照，由已有的经过验证缓存降级机制展示实际截止时间和失败提示。不能把不同日期的收盘估值或另一来源的股本悄悄当作当前东财市值。

备用聚合与全量成分股使用独立的 v3 缓存，保留原有东财缓存键。服务端与浏览器均拒绝旧新浪分类快照和没有同日东财市值的新快照。主动刷新绕过短期报价复用，并重新请求名单、报价和市值；行情时间与抓取时间分别展示。

v3 必须明确声明来源、快照标记、上市范围、行业及市值覆盖。交易日、报价时间对应的北京时间日期和市值日期必须一致；报价覆盖数必须与涨、跌、平及不可用家数守恒。浏览器也检查成分股和盘面数组成员，避免损坏的本地缓存进入组件。无效缓存会被拒绝，不能通过补写质量标记改成有效行情。

今日盘面所有指标以报价交易日为基准，不用抓取当天的自然日期查询池。前一交易日及历史窗口取自上证指数实际日线日期，不能用“工作日”或“涨停数大于零”猜测。东财池接口会把超出最新可用日期的查询钳制到旧池；因此检查全局 `qdate` 上限、返回码和池完整性。历史请求的 `qdate` 仍是最新池日期，不要求它等于历史查询日期。池曲线限制在最近 15 个实际会话，避免将超出当前可用窗口的空响应展示为零。

备用报价路径也查询同交易日的池，并恢复热度、强弱、连板、前一交易日涨停表现和池历史曲线。只隐藏确实缺数据的依赖指标。最近一次“次日表现”使用前一交易日涨停股在盘面交易日的有效报价；更早的次日成功率没有日线数据时保持未知，不能跨过缺失日期把后一天当次日。同日已有完整收盘盘面且涨跌统计一致时，今日盘面优先保留完整快照；上午数据和不同日期不获得这个优先权，该规则不启用于热力图或个股服务。
