# 个股资讯

A股页面K线下方的个股分析面板中并列提供「资讯 / 资金动向」。右侧仅保留「自选 / 推荐」。资讯包含新闻、公告、研报三个分类；顶部展示当前图表股票名称、代码，切换股票保持资讯模式及分类。标题以新标签打开原文，来源缺失时明确标注。

沿用 tangle 的腾讯财经接口，由浏览器直接请求，只有打开资讯及切换分类才取数。每个股票/分类取最新20条，内存缓存5分钟，最多120组，并合并相同请求。刷新/重试绕过缓存。10秒超时；空列表和接口失败分别提示；换股或卸载后忽略旧响应。服务端、数据库及登录逻辑不变。

文件：`src/components/StockNewsPanel.jsx`、`src/lib/stockNews.js`。资讯链接仅接受HTTP/HTTPS，文本由React转义；分类按上游接口提供，不自行推断内容类别。美股页面暂不提供此入口。

验证：浏览器真实加载埃科光电的三类资讯，切换曲美家居确认联动；390px窄屏下资讯区宽309px，无内容撑宽；桌面保持320px侧栏，列表独立滚动。测试涵盖市场代码、响应解析、链接协议、去重、缓存隔离、并发合并及失败重试。
