## 一、包含处理与分型

### 1. 区间及包含

每根K以最高价 `H`、最低价 `L` 表示。相邻两根满足以下任一项就视为包含，含等高、等低和完全相同区间：

```text
H1 >= H2 且 L1 <= L2
或
H2 >= H1 且 L2 <= L1
```

没有包含则保留为两根独立处理K；存在包含则按方向合并。

### 2. 方向及顺序

用此前已经保留的两根处理K `A、B` 确定 `B` 与新K合并的方向：

- `A.H < B.H`：向上，合并后 `H=max(B.H,新H)`、`L=max(B.L,新L)`。
- `A.H > B.H`：向下，合并后 `H=min(B.H,新H)`、`L=min(B.L,新L)`。
- 函数还保留 `A.H == B.H` 时不合并、直接返回新K的分支；有效非包含前对不会等高。

逐根、从左到右处理，下一根与已经合并出来的区间比较。保存每次合并记录和所有原始来源K。

开头没有明确前趋势时，若唯一保留K与下一根包含，就用下一根替换它，继续寻找第一对非包含K。此前不确定前缀不反推合并、不产生结构；这是当前初始化约定。2026-10-15所述起始不对称属于旧版本，当前已换成此策略。

### 3. 顶、底几何条件

对相邻三根处理K `左、中、右`：

| 类型 | 同时满足的条件 | 价格 |
| --- | --- | --- |
| 顶 `G` | `H中 > H左`、`H中 > H右`、`L中 > L左`、`L中 > L右` | `H中` |
| 底 `D` | `H中 < H左`、`H中 < H右`、`L中 < L左`、`L中 < L右` | `L中` |

使用严格不等式。几何成立不要求阴阳线组合，也没有额外要求第三根突破第一根另一端。必须已有右侧处理K，只有两根时不输出分型；但几何扫描本身不检查右K是否收盘，不能把所有圆点称为收盘确认信号。

`findFractals` 还保留一条防重复规则：当已收集至少两个分型时，若新分型与最后一个同性质，就跳过这个新分型。这不是按力度打分择优。

### 4. 定位及主图输出

向上合并以最高价来源K的时间定位，向下合并以最低价来源K定位；合并出现相同极值时取较右原K。然后将分型时间、价格映射回普通K线图，并不把主图蜡烛替换成合并K。

圆点列表 `fx` 不是全量局部几何分型：

1. 每笔内部的分型列表去掉第一个分型，再汇总。
2. 补入未成笔区间中时间更晚的分型。
3. 按分型时间去重。

因此首笔起始分型可以没有圆点，但仍作为笔端三角形存在。首笔锚点筛选也可能移除更早的局部分型；这种起点选择参与笔计算，不能全部称为纯显示过滤。

## 二、笔

### 1. 起点及候选终点

尚未成笔时，从当前区间最早分型开始，在同性质分型中选更极端者：底选更低、顶选更高；相同价格保留较早起点。从该分型的左侧处理K开始检查首笔。

对每次待成笔区间，取第一个分型作为起点：

- 底起点：寻找时间更晚、顶价高于起点底价的顶分型，在其中选最高顶。
- 顶起点：寻找时间更晚、底价低于起点顶价的底分型，在其中选最低底。
- 同价候选不替换较早终点。先选极值候选，再检查成笔条件；不满足时本轮不成笔。

### 2. 成笔硬条件

除了异性质、时间顺序和上述价格方向，还必须满足：

1. 两端完整三K分型之间，至少有一根不属于任何一端分型的**处理后独立K**。
2. 从起点分型左K到终点分型右K，至少7根处理K，`MIN_BI_LENGTH=7`。最小结构为 `3 + 1 + 3`；包含进去的额外原始K不能充当独立K。
3. 两端分型中间K的区间不得满足下面的严格包含表达式：

```text
(起H > 终H 且 起L < 终L)
或
(起H < 终H 且 起L > 终L)
```

这里必须按实际表达式理解：等边界不会仅因本条被排除，且本条不是一条额外的完整“四边均严格有序”判断。本文不把这段代码直接等同于第77课所有边界已经证明正确。

成笔后，下一待分析区间从终点分型的左K起保留，以保留必要重叠。

### 3. 延伸与回退

每加入一根K，先尝试增加笔，再检查最后一笔：末笔向上而未完成区间最后处理K的高点严格超过末笔高点，或末笔向下而其低点严格低于末笔低点时，撤回末笔，把该笔的处理K接回待分析区间。接回时保留两根K的衔接重叠，后续重新合并、成笔。

因此新行情可以改变尾部笔链，连续处理时也可能撤回多个旧端点；不能把当前笔链当作永久不变的历史信号。

### 4. 笔链、确认及动态尾端

当前 `bi` 与 `segmentBi` 内容相同，包含每笔的起点和最后一笔终点。最后一笔终点始终标为未确认；它成为后继合法反向笔的起点，并且必要原始K证据完成后，才可供线段确认使用。

确认检查覆盖对应笔起点分型左K的原始来源开始，直到该笔本轮形成K：

| 原始K的 `complete` | 确认约定 |
| --- | --- |
| `true` | 可以在这根K的时间确认其完成 |
| `false` | 不确认，不能仅凭后来又有K就覆盖这个明确标识 |
| 未提供 | 等后继同周期K出现，用后继K的时间记录完成获知时刻 |

`confirmed_time` 取笔形成时刻及全部必要K完成获知时刻的最大值；未满足则为空。该状态随本次笔链重算，笔被撤回时相关确认结构也撤回。

另有 `pending` 动态方向极值：从最后笔端原K起查找后续原始K，按下一笔方向取最高或最低，平价保留先出现者。画在真实极值发生K，不平移到最新K；始终未确认。

黄色笔线 `biLine` 把当前笔链和动态尾端连在一起，动态尾段同样是实线。因此图上黄色实线本身不代表所经端点均已确认。

## 三、线段

### 1. 输入与最低结构

`buildSegments` 只消费连续的 `confirmed === true` 笔端前缀；遇到未确认、非有限价格、与前点同性质或时间未递增，立即停止，不跨过该点继续取后面的点。

起点从第一处前三笔有正宽交集的位置开始：

```text
max(前三笔低点) < min(前三笔高点)
```

仅相触一点不算。完成段须至少3笔、笔数为奇数；向上段终价高于起价，向下段终价低于起价。候选终点之后的反向前三笔也须满足正宽交集。

### 2. 特征序列

- 向上线段取向下笔作为特征元素；向下线段取向上笔。
- 每个元素是该笔两个端点构成的价格区间，保留高低来源端点。
- 同一序列顺序处理包含：有此前非包含元素时据其方向取高高或低低；序列开头方向取当前线段方向。
- 特征元素合并的等价极值保留较早来源，与原始K合并取右侧的时间约定不同。
- 跨假设分界点的左元素与中心元素不直接合并；分界点右侧同性质元素继续正常合并。
- 上行段检查标准特征序列顶分型，下行段检查底分型，仍使用高低同时严格比较。

### 3. 确认分支

左、中心元素的区间只要相触或重叠就算无缺口；严格分离才是特征缺口，它不是原始K跳空。

| 分支 | 当前实际要求 |
| --- | --- |
| `feature_no_gap` | 左与中心无缺口，右侧标准化后形成对应顶／底分型，且中心极值仍对应假设终点，即可确认旧段结束 |
| `feature_gap_reverse_fractal` | 第一序列有缺口并形成分型后，从假设终点构造反向线段的标准特征序列，须再形成相反分型；不额外要求填补前缺口，也不递归继续分两种缺口情形 |
| `first_stroke_break` | 无缺口时，第一反向笔已触及或越过前特征元素的反向边界；还须后续第3、5等奇数反向笔严格越过第一反向笔结束价，才确认旧段。期间若先触及或越过旧段终点，取消这个候选 |
| `reverse_feature_fractal` | 第二序列已提供相邻反向段的结束证据时，同时输出对应反向段，沿用必要确认依据 |

首笔破坏的触发等值：上段 `中心低 <= 左低`，下段 `中心高 >= 左高`。后续越过首笔结束价仍用严格比较。此分支先于普通特征分型分支执行。

有缺口分支若尚未形成反向分型就先触及／越过旧转折端点，候选失效；同一步先查新分型，再查越界，保留先形成确认、再跨越旧端的处理顺序。

多个候选都满足时，选所需确认笔端索引最早的；同索引保留先遍历的终点。新段起点与上一段终点共用。后一段确认不能早于前段确认。

### 4. 端点、确认时刻与发展中段

完成段分别保存起止端点、笔数、内部高低极值及来源、确认分支和确认依据。内部极值不强制等于起止端点。

`confirmed_endpoint_time` 是最后必要证据对应的笔端时间；`confirmed_time` 汇总截至该证据点所有必要笔端的确认时间，不能回填成旧转折点当时就知道。它是本次已加载历史复算的依据，不是跨请求的首次观察日志。

发展中段也必须先有前三笔重叠的候选结构。随后在主图入口延伸到起点之后原始K的同方向极值，平价保留较早K；标为未确认。确认段画粗实线，发展中段画虚线。上游笔回退会同步重算、撤销失去依据的线段。

## 四、当前“中枢”：滑动笔重叠区

### 1. 输入层次和状态

当前色框直接调用 `buildZs(bi)`；不是 `buildZs(segments)`，也没有走势类型的递归级别构建。界面标签为“滑动笔重叠区”。

它不接入 `pending` 的额外动态极值，但也**没有按 `confirmed:true` 过滤当前笔链**。因此最后尚未供线段确认的笔端可以参加重叠区。不能将色框称为“完全由线段确认笔构成”。

### 2. 形成与延伸

每两个相邻笔端构成一个笔区间：

```text
笔H = max(起价,终价)
笔L = min(起价,终价)
```

从每一笔作为起点，独立检查连续3笔：

```text
ZG = min(H1,H2,H3)
ZD = max(L1,L2,L3)
要求 ZG > ZD
```

正宽交集成立才创建候选；零宽相触不创建。

后续笔只要 `笔H >= ZD 且 笔L <= ZG` 就并入，触及边界也算延伸。ZG/ZD始终固定为最初3笔的交集，不随延伸收窄。包含形成的3笔在内，最多9笔；遇到不重叠笔立即停止该候选。

### 3. 多个候选与绘图

每个笔起点独立尝试，因此不同候选可以在时间和价格上交叠。若一个候选的笔索引起止范围被另一个严格包住，就删去较短候选；这里比较的是时间顺序范围，不检查价格框是否包含。

返回字段为开始／结束时间、ZG、ZD、`ZZ=(ZG+ZD)/2`、笔数和 `algorithm='sliding_window'`。色框从第一笔起点画到最后纳入笔的终点；结束时间最晚的框标为当前参考，若结束时间相同则保留遍历中先遇到的那个。这个“当前”只是选择最新参考框，不表示已经证明其仍在严格中枢延伸。

主图边界来源优先从形成3笔的4个端点中查找；研判文本另外优先使用框内第一根触及相同边界价的原始K。两者价格相同，来源时间可能不同。

没有实现严格中枢离开／首次回试的生命周期，也没有中枢级别扩张、递归走势中枢或基于其确认的三类买卖点。

## 五、分型详情中的附加形态标签

这些标签不决定分型、笔、段或重叠区是否成立，仅用于详情描述。只有三根处理K各自都只来自一根原始K、OHLC合法且满足分型几何时才适用；存在包含合并时不套用实体形态分类。

默认软件阈值：实体占本K振幅至少60%视为满足长实体占比；非零小实体不超过第一根实体的50%；长影线占振幅至少50%，且不短于实体。这些是软件比例条件，不是对绝对长度的判定。

| 标签 | 顶分型 | 底分型（价格镜像） |
| --- | --- | --- |
| 中继倾向 | 第一根为满足长实体占比的阳线，第二、三根为非零小实体 | 第一根为满足长实体占比的阴线，第二、三根为非零小实体 |
| 力度较大 | 第二根长上影或满足长实体占比的阴线；第三根不同时满足“阳线且收在第二根区间中点之上” | 第二根长下影或满足长实体占比的阳线；第三根不同时满足“阴线且收在第二根区间中点之下” |
| 相对高／低点特征 | 第三根最低严格低于第一根最低，且收盘不高于第一根区间中点 | 第三根最高严格高于第一根最高，且收盘不低于第一根区间中点 |

条件可同时满足，主标签按“相对高／低点 → 力度较大 → 中继倾向”展示；这不是概率或交易确认。
