# 腾讯行情显示排查（2026-10-28）

## 确认的问题和修复

用户报告腾讯接口导致页面不显示，但尚未给出市场、证券代码、周期或原始错误，因此不能将本次发现等同于用户那条请求的唯一原因。

实测发现：腾讯 `sh600851,month,,,1000,qfq` 返回 HTTP 200、390 根月 K。1994-07-29 的原始数据为 `0.322 / -0.074 / 0.330 / -0.107`（开/收/高/低），成交量 `10993.550`。日期、顺序、价格关系和成交量合法；累计现金调整后的历史价格可以穿过零。

当前代码将所有价格都按原始成交价要求大于零，拒绝该响应，并进入较短历史重试；主图纵轴下限又被固定在零，接受数据后仍会把负价蜡烛画到主图区外。

修复内容：

- 行情完整性校验新增显式 `adjusted: true` 契约，腾讯/东方财富 A 股复权请求传递该标记。原始成交价仍要求为正，完整字段、日期、顺序、OHLC、成交量检查保留。
- 主图含零或负价格时，价格轴下沿使用实际价格范围。
- 已验证分钟前复权后的 30 分钟子 K 向 4 小时聚合传递同一契约。这个聚合问题以明确现金分红的测试复现，未在本次真实分钟样本中出现。
- 展开 390 根历史后，FSL 的局部标签搜索会在面板仍有空位时放置重叠文字。改为全绘图区独占槽位，保留交叉位置、标签、日期和引线。
